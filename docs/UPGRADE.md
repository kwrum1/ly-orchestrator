# 升级与回滚

## 支持范围

- 1.0.x → 1.0.x：支持原地升级；
- 0.x → 1.0.x：支持，但升级前请先做配置备份；
- 跨大版本降级：不支持，请用对应版本 ISO 重装后恢复配置。

## 升级方式

### 控制台

1. 下载 `ly-route-orchestrator-<version>-amd64.tar.zst`；
2. 登录控制台，进入 **系统 → 升级 / 回滚**；
3. 上传升级包，确认版本与校验值；
4. 执行升级，等待服务重启；
5. 刷新页面，确认版本与运行状态。

### 升级内容

升级包包含：

- `ly-route-control` 控制面；
- `vpp-apply` 下发组件；
- 编排器 Web 管理界面与静态资源；
- `etc/ly-route/version.env`；
- 必要的服务单元与配置模板。

升级只替换编排器相关组件，不改动管理口地址、业务配置与网络拓扑。

## 升级后检查

```bash
/usr/lib/ly-route/ly-route-control --version   # 应为目标版本
systemctl status ly-route-control-api vpp
curl -sk https://127.0.0.1/api/v1/health
```

控制台应显示新版本，编排组、策略、镜像与旁路配置保持有效。

## 回滚

- 控制台 **系统 → 升级 / 回滚** 选择上一版本；
- 升级失败时按页面提示回滚，或使用上一版本升级包重新安装；
- 严重故障：使用对应版本 ISO 重装，然后从配置备份恢复。

## 注意事项

- 升级过程中不要断电；
- 升级前确认管理口可达；
- 自定义的 `/etc/ly-route` 之外的文件可能被覆盖，请自行备份；
- 升级包必须与架构匹配，当前仅提供 x86_64（amd64）。
