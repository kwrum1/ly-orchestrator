# 06 · Panabit 安装与学习计划

> 目的：用真实 Panabit 设备/虚拟机观察“专业网关”的信息架构、策略流、会话视图和
> 表格/弹窗交互，提炼可迁移模式。**不把 Panabit 的功能当成 Ly Route 的功能**，
> 不复制其素材/商标，不在生产网络做实验。

## 1. 学习目标（按优先级）

| 优先级 | 目标 | 观察点 | 迁移到 Ly Route |
| --- | --- | --- | --- |
| P0 | Any→Any 默认上网策略 | 策略序号 1–65535、默认策略放最大序号、动作 NAT、NAT 线路 | 策略路由空表引导、优先级说明、默认策略预填 |
| P0 | 会话记录/筛选/详情 | 在线用户 → IP → 连接信息；筛选条件；分页；字段 | 在线用户抽屉、会话表、筛选/分页 |
| P0 | 表格运维密度 | 列设置、自动刷新、搜索、批量、行内操作 | DataTable/Toolbar/列设置/自动刷新 |
| P1 | 策略列表可读性 | 序号/条件/动作/线路/状态/命中 | 条件摘要、状态列；命中列因无 API 不做 |
| P1 | 弹窗表单分节 | 策略路由大弹窗；匹配条件/执行动作分区 | 960px 策略弹窗、分节表单 |
| P1 | 首页/监控层级 | 流量概况 KPI、趋势、Top、系统信息 | 首页 KPI/趋势/Top/健康 |
| P2 | 对象/流控/端口映射 | 对象组、限速、映射字段 | 只对照现有字段，不扩功能 |
| P2 | 错误/空态/危险操作 | 保存/生效、失败提示 | Apply 状态机、确认弹窗 |

## 2. 部署方式选择

### 2.1 方案 A：ESXi（有现成 ESXi 时优先）

| 项 | 建议 |
| --- | --- |
| 虚拟机 | 新建 VM，客户机 OS 先选 **Other Linux (64-bit)**；若 ISO 不识别，再试 **FreeBSD (64-bit)** |
| CPU | 2 vCPU（免费版最低 2 核） |
| 内存 | 4 GB（最低 2 GB；4 GB 更稳） |
| 磁盘 | 20–40 GB（学习够用；日志/升级留余量） |
| 网卡 | 3 张：1 管理 + 1 WAN + 1 LAN；优先 E1000（兼容性），若识别正常再试 VMXNET3 |
| 光驱 | 挂载官方 ISO |
| 网络 | 独立 vSwitch/端口组；管理口不接生产 LAN；WAN 接实验上游；LAN 接实验客户端 |
| 快照 | 安装完成、初始配置完成各打一个快照 |

### 2.2 方案 B：独立 VM（无 ESXi 时）

可选 Proxmox VE / VirtualBox / QEMU/KVM。推荐 Proxmox（快照/网络桥接方便）：

- 2 vCPU / 4 GB / 20 GB；
- 3 个 virtio/e1000 网卡，分别接 `vmbr-mgmt`、`vmbr-wan`、`vmbr-lan`；
- `vmbr-wan` 只接实验上游（OpenWrt/软路由/NAT 出口），`vmbr-lan` 只接实验客户端；
- 管理口用独立 host-only/NAT 网络，避免暴露到办公网。

> 不建议在唯一的物理出口路由器上直接装 Panabit 学习；会中断生产网络。

## 3. 网络拓扑（隔离实验）

```text
                 ┌──────────────────────────────┐
                 │ 实验上游（OpenWrt / NAT / DHCP）│
                 │ 192.168.50.1/24               │
                 └──────────────┬───────────────┘
                                │ vmbr-wan
                 ┌──────────────┴───────────────┐
                 │ Panabit VM                    │
                 │ eth0 mgmt 192.168.70.10/24    │
                 │ eth1 WAN  192.168.50.2/24     │
                 │ eth2 LAN  192.168.60.1/24     │
                 └──────────────┬───────────────┘
                                │ vmbr-lan
                 ┌──────────────┴───────────────┐
                 │ 实验客户端 VM                  │
                 │ DHCP 192.168.60.100-200       │
                 └──────────────────────────────┘
管理网络：vmbr-mgmt / host-only 192.168.70.0/24，仅宿主机访问
```

地址可按实验室调整；原则是 **管理、WAN、LAN 三网分离**，不接生产。

## 4. 安装步骤（ESXi/VM 通用）

1. **下载**：从 Panabit 官网下载中心获取免费版 Linux ISO：
   `https://www.panabit.com/download`（免费版入口 `https://www.panabit.com/Panabit-FreeVersion`）。
   以官网当期版本为准；网上示例版本 `PanabitFREE_TANGr7p4_20250620_Linux.iso` 仅作参考。
2. **校验**：记录文件名、版本、SHA256/MD5（官网提供则核对）；放入 ISO 存储。
3. **创建 VM**：按 §2 配置；光驱挂 ISO；启动。
4. **安装向导**：
   - 选择 `Yes` / `OK` 接受；
   - 选择安装磁盘（只选实验虚拟盘，避免误写）；
   - 选择管理网卡（eth0）；
   - 配置管理口 IP/掩码/网关（如 `192.168.70.10/24`，网关可空或指向管理网）；
   - 等待安装完成并重启。
5. **登录**：
   - 浏览器访问 `https://192.168.70.10`（自签证书告警属正常，实验环境继续）；
   - 默认账号 `admin`，默认密码常见为 `panabit`；不同镜像可能不同，以控制台/官方说明为准；
   - **首次登录立即改密**，不要保留默认密码。
6. **基础检查**：版本、时间、License/免费版规格、接口识别、管理口连通性。

> 网上常见默认管理地址 `10.8.8.8` 或 `192.168.0.200`，是不同版本/镜像的默认值；
> 不要照抄，安装时以控制台显示和实际配置为准。

## 5. 学习场景与操作脚本

### 场景 1：接口与线路

1. 【网络设置/网络管理】→ 网卡设置：确认 eth0=管理、eth1=WAN、eth2=LAN。
2. LAN/WAN → 新增 WAN：类型选 DHCP 或静态（实验上游 `192.168.50.1`）。
3. LAN/WAN → 新增 LAN：`192.168.60.1/24`，命名 `lan-lab`。
4. 记录：接口列表字段、状态、速率、操作入口、保存后的反馈。

### 场景 2：Any→Any 默认上网（重点）

1. 【网络管理】→【IPv4 路由/NAT】→【添加】。
2. 策略序号填 **65535**（最大值，给后续策略留空间）。
3. 匹配条件全部“任意”（源/目的地址、端口、协议）。
4. 执行动作选 **NAT**，NAT 线路选 WAN。
5. 保存；在客户端 `ping`/打开网页验证。
6. 观察列表：序号、条件摘要、动作、NAT 线路、状态、命中/匹配次数、批量操作。
7. 记录：默认策略为什么放最大序号、列表如何表达“任意”、保存后是否立即生效。

> Ly Route 对应：策略路由 priority 1–65535，action=nat/route，match 为空=任意，
> egress=WAN/WAN 组/代理。**Ly Route 没有路由策略 hit_count，不要照搬“命中次数”列。**

### 场景 3：策略优先级

1. 再加一条策略，序号 **100**（小于默认），源地址=实验客户端 IP，动作 NAT 到另一条 WAN
   （若只有一条 WAN，可改为“路由”到 LAN 或观察匹配顺序）。
2. 保存后观察匹配/命中变化（Panabit 有；Ly Route 无）。
3. 调整序号/禁用/启用，观察行为。
4. 记录：序号与优先级的关系、批量启用/禁用、策略变更对命中的影响。

### 场景 4：端口映射

1. 【网络管理】→【端口映射】→【添加】。
2. 映射线路=WAN，外部端口=8443，协议=TCP，内网主机=实验客户端，内网端口=443。
3. 从 WAN 侧访问 `https://<WAN_IP>:8443` 验证。
4. 记录：外部 IP/端口范围/协议/内网主机/内网端口/回流（hairpin）字段。
5. Ly Route 只保留现有字段；外部 IP/hairpin/full_cone 是否暴露需产品批准。

### 场景 5：在线用户与会话（重点）

1. 【系统概况】→【在线用户】→【所有用户】。
2. 观察列：IP、MAC、连接数、上/下行速率、在线时长、接入方式、备注、操作。
3. 点击 IP → **IP 档案**；观察 Tab：流量概况、连接信息、对端概况、虚拟身份、共享用户、
   移动终端、账号信息。
4. 进入【连接信息】：查看会话字段、筛选条件、分页、排序、刷新。
5. 记录：
   - 哪些字段 Ly Route 有（源/目的/NAT/协议/端口/字节/时长）；
   - 哪些没有（虚拟身份/共享用户/移动终端/账号/重传/最大包长）；
   - 抽屉宽度、表格密度、筛选栏布局、空态。
6. 截图：在线用户列表、IP 档案概览、连接信息筛选前后。

> Ly Route 不复制无数据的 Tab；会话抽屉只做“概览 + 会话”。

### 场景 6：DHCP / DNS / 对象 / 流控（按需）

- DHCP：服务列表 → 选择 LAN → 地址池/网关/DNS/租约；静态绑定。
- DNS：DNS 管控/策略；观察“所有域名/域名组/线路/上游/动作”的表达。
- 对象：IP 组/域名组/协议组；观察成员编辑、导入、关联策略。
- 流控：限速/阻断、方向、速率；观察策略列表与状态。
- 记录可迁移的表格/表单模式，不记录 Ly Route 没有的字段。

### 场景 7：配置备份与升级

1. 系统维护 → 配置备份/导出；保存到实验机。
2. 查看升级中心/版本信息；不要在生产设备升级。
3. 记录：危险操作确认、升级提示、备份文件命名。

## 8. 清理与安全

- 学习结束：关闭 VM；删除实验 VM/磁盘/快照；移除实验端口组/网桥；确认无残留 DHCP/DNS。
- 不把 Panabit 管理口暴露到公网；不改办公网网关；不在生产交换机上做镜像/桥接。
- 不使用来源不明的 ISO；核对官网/校验值。
- 免费版有连接数/IP/线路限制（官方免费版页面：65,536 并发连接、256 并发 IP、8 条 LAN+WAN
  线路），学习足够；不要用限制数据推断 Ly Route 性能。
- Panabit 的界面/图标/文案仅用于学习，不进入 Ly Route 生产资源。

## 9. 从 Panabit 到 Ly Route 的结论（预期）

| Panabit 模式 | 采纳 | Ly Route 做法 |
| --- | --- | --- |
| Any→Any 默认 NAT 放最大序号 | ✅ | 空表引导 + 预填 65535；说明“数字小优先” |
| 策略列表显示命中次数 | ❌ | 后端无 hit_count；只显示 runtime_state |
| 在线用户 → IP 档案多 Tab | ⚠️ 部分 | 只保留概览 + 会话；无数据 Tab 不做 |
| 会话筛选/分页/刷新 | ✅ | 抽屉内关键字/协议/状态 + 20/页 |
| 列设置/自动刷新/搜索 | ✅ | DataTable Toolbar |
| 大弹窗分节 | ✅ | 960px 策略弹窗，分“匹配/动作/高级” |
| 批量启用/禁用/删除 | ⚠️ | 仅在后端支持批量语义时开放 |
| 应用协议/DPI/虚拟身份 | ❌ | 产品边界外，无数据 |
| 复杂全锥/CGNAT 规则 | ⚠️ | 只保留后端 `full_cone` 布尔，不扩规则 |
