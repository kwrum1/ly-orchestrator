# 04 · 首页方案与关键页面线框

> 线框是布局与信息层级规范，不是最终视觉稿。所有模块标注了真实数据源；
> 没有数据源的模块一律不画。

## 1. 首页信息架构

首页回答五个问题，按优先级从上到下：

1. **设备是否正常？** 健康、运行态、待应用、降级原因。
2. **现在流量怎么样？** 上/下行、连接数、在线用户、出口。
3. **哪条线路/接口有问题？** WAN 出口、物理接口、逻辑出口健康。
4. **谁在用？什么最多？** Top 用户/连接/域名。
5. **最近发生了什么？** 审计事件、最近 apply。

首页不重复“流量概况”的完整双图；完整分析在 `/traffic`。

### 1.1 首页模块与数据源

| 模块 | 数据源 | 关键字段 | 空/异常 |
| --- | --- | --- | --- |
| 页面标题/健康 | `/health`, `/capabilities` | status, degraded, dependencies | 依赖全部展示；degraded 显示原因 |
| 状态带 | `/dashboard/summary`, `/runtime/status`, `/firmware/update/status` | uptime, system_time, platform, last_apply, version | 未知 `--`；版本 `dev` 原样 |
| KPI 下行/上行 | `/telemetry/traffic-trend` | totals.download_bps/upload_bps | 无出口显示 `--`，不是 0 |
| KPI 活动连接 | `/telemetry/dashboard` | sessions | 不可用显示 `--` |
| KPI 在线用户 | `/telemetry/online-users` | items 数 | 无租约/邻居显示 `0` 或 `--`（按 capability） |
| KPI 逻辑出口 | `/telemetry/traffic-trend` | series.logical_egresses 长度 + health | 无出口显示 `0` + “未配置” |
| WAN 趋势 | `/telemetry/traffic-trend?window=` | series + samples | 无采样显示空态；degraded 显示原因 |
| WAN 出口 | 同上 + `/gateway/wan-links`, `/gateway/wan-groups`, `/proxy/egresses` | id/name/kind/health/current | 只显示已配置出口；无出口引导创建 |
| 接口状态 | `/telemetry/interfaces` | name, role, link_state, speed, rx/tx bps, mode | 无接口/无遥测显示原因 |
| 系统健康 | `/dashboard/summary`, `/runtime/status` | cpu/mem/load, components, last_apply | 不可用显示 reason |
| Top 列表 | `/telemetry/online-users`, `/telemetry/top-sessions`, `/telemetry/top-domains` | 见 01 文档 | 各自空态 |
| 最近事件 | `/telemetry/audit-events` | timestamp, actor, action, status | 空态 |

### 1.4 首页状态与交互

- 顶栏健康 pill：`正常` / `降级（3）` / `读取中`；点击打开右侧“健康详情”抽屉，列出
  `dependencies` 的 name/state/reason，不跳页。
- `待应用 N`：来自资源 `runtime_state === desired_not_applied` 计数 + `last_apply` 非 running；
  点击打开 Apply Banner/抽屉。无待应用时不显示。
- 刷新：只刷新首页关键 query；显示“更新于 HH:mm:ss”。
- 时间窗：`实时 / 5分钟 / 1小时 / 24小时`，与 `/traffic` 共享偏好。
- 图例：点击隐藏/显示出口；颜色固定；隐藏状态持久化。
- WAN 出口行点击 → `/traffic` 并聚焦该出口；未配置出口不显示。
- 接口卡点击 → `/interfaces`；管理口显示锁图标。
- Top 用户行点击 → 打开在线用户抽屉；Top 连接/域名“查看全部” → 对应页面。
- 最近事件“查看全部” → `/system/runtime` 的审计区（若产品不开放独立审计页，则展开抽屉）。
- 任何 API 失败：模块内错误块 + 重试，不拖垮整页；首屏关键模块（健康/KPI）失败才显示页面级提示。
