# 05 · 交互规范与差异表

> 原则：减少“猜”，增加“确认”；保存与生效分开；任何长操作都有可追踪状态；
> 所有表格/弹窗/抽屉都能用键盘完成。

## 1. 全局导航

### 1.1 侧栏

- 分组：概览 / 监控 / 网络 / 策略与对象 / 系统。
- 每组可折叠；当前页所在组默认展开；折叠状态持久化。
- 菜单项：图标 18px + 文案 13px；选中态浅蓝底 + 左侧 2px 蓝条。
- 侧栏底部：版本号、健康点（可选）、折叠按钮。
- ≤ 1200px 可折叠为 64px 图标栏；≤ 900px 变抽屉，顶栏汉堡按钮打开。
- 菜单搜索：输入即过滤；`Ctrl/Cmd+K` 打开命令面板（页面 + 常用动作）。

### 1.2 顶栏

- 左：产品标识、当前页面面包屑（分组 / 页面）。
- 中/右：全局搜索、健康 pill、待应用 pill、用户菜单（改密/退出）。
- 健康 pill 点击打开“健康详情”抽屉；待应用 pill 点击打开 Apply 抽屉。
- 只读角色：顶栏显示“只读”徽标；所有写按钮禁用并 title 说明。

### 1.3 命令面板（Ctrl/Cmd+K）

- 只搜索**页面和动作**，不搜索业务数据（后端无全局搜索 API）。
- 项：页面名、别名、常用动作（新增 WAN/LAN/策略/映射、应用运行态、刷新）。
- 键盘：↑↓ 选择、Enter 执行、Esc 关闭；无结果时显示“未找到页面或动作”。

## 2. 标准列表页操作流

```text
进入页面
  → 并行加载：列表 + 依赖资源 + capabilities
  → 骨架（表头保留）
  → 成功：表格 / 空态
  → 失败：错误块 + 重试（保留旧数据）
  → 用户点“新增”
  → 弹窗/抽屉（分节表单）
  → 前端格式校验
  → 提交：保存 desired state
      ├─ 422：字段/业务错误，保留输入
      ├─ 403：只读提示
      ├─ 5xx：错误 + request_id + 重试
      └─ 200：关闭弹窗，行内“待应用”，触发 apply
  → apply 状态机（见 §5）
  → 回读 + 刷新列表
```

### 2.1 新增/编辑

- 新增：标题“新增 X”；主按钮“保存并应用”；次按钮“仅保存”（是否保留由产品确认）。
- 编辑：标题“编辑 X”；字段预填；密码/密钥留空表示不变。
- 保存中：按钮 loading、表单只读、禁止关闭；ESC 不关闭。
- 成功后：Toast“已保存，正在应用”；列表行显示“待应用”；apply 完成后再变“已应用”。
- 失败后：弹窗不关闭；顶部错误摘要 + 字段错误；`request_id` 可复制。
- 脏表单关闭：确认“放弃未保存的修改？”；浏览器离开用 `beforeunload`。

### 2.2 删除

- 行内删除 → 确认弹窗（420px）：
  - 标题“删除 X？”
  - 对象名称、类型、关键标识（IP/端口/线路）。
  - 影响：被哪些策略/映射/群组引用；删除后需 apply。
  - 主按钮红色“删除”；次按钮“取消”。
- 删除中禁用；成功后 Toast + 行移除 + apply。
- 删除失败（被引用/后端拒绝）：展示后端 message，不强制删除；提供“查看引用”。
- 管理口/当前登录用户等受保护对象：不显示删除，或禁用并说明原因。

### 2.3 批量操作

- 仅在后端有明确批量语义时开放。当前多数资源没有 batch 端点，**不显示“批量操作”假按钮**。
- 如后续加：选择后出现批量条（已选 N），操作需二次确认；逐条失败要列出。
- 全选只选当前页；跨页选择需明确提示。

## 3. 表格交互

| 行为 | 规范 |
| --- | --- |
| 排序 | 点击表头 asc → desc → none；仅对已加载数据排序 |
| 筛选 | 工具栏输入/下拉；客户端过滤；显示“筛选后 N / 总 N” |
| 分页 | 20/50/100；页脚“共 N 条”；空表不显示分页 |
| 列设置 | gear 打开 checkbox；至少 3 列；持久化 |
| 密度 | 紧凑/默认/舒适；全局偏好；表格内不单独改行高 |
| 行点击 | 有详情抽屉的页面打开详情；操作按钮 stopPropagation |
| 复制 | IP/MAC/端口/域名点击复制；toast |
| 横向滚动 | 表头/操作列 sticky；滚动阴影 |
| 空态 | 图标 + 标题 + 说明 + 主操作；不渲染空白行 |
| 加载 | 表头 + 5 行 skeleton；刷新保留旧数据 |
| 错误 | 表格区域错误块；不把错误当空数据 |
| 自动刷新 | 默认 5–15s（按页面）；页面隐藏/弹窗/编辑时暂停；显示“更新于” |

## 4. 表单模式

### 4.1 分节

复杂表单统一分节：

1. 基本信息（名称/序号/类型）
2. 匹配条件（地址/端口/协议/域名组）
3. 执行动作（NAT/路由/限速/阻断/解析/拉黑）
4. 高级（下一跳/全锥/备注/文件导入）

默认只展开 1–3；高级折叠。错误定位到节标题 + 字段。

### 4.2 地址条件编辑器

- 类型：IPv4 地址/网段、IPv6 地址/网段、IPv4 起止范围、IP 组。
- 多行 OR；空列表 = 任意（显示“任意”，不是空输入）。
- 删除行有确认？单行直接删除可撤销（toast + 撤销）；不要每次弹窗。
- 校验：格式/范围；组是否存在由后端校验。
- 键盘：Enter 新增行；Tab 顺序合理；删除按钮有 aria-label。

### 4.3 端口/协议

- 单端口或范围（如 `80,8080` / `8081-8090`）按后端支持；UI 不自行拆分。
- 协议选择：Any/TCP/UDP/ICMP（按页面后端支持）；不要提供未支持项。
- 端口 1–65535；0 不作为有效端口（除非后端明确 0=任意）。

### 4.4 DNS 策略

- 目的域名 = “所有域名”时，明确说明 catch-all；规则列表为空，解析设置写在 miss。
- 解析上游：单 IP 或 `https://` DoH；前端只做基础格式检查。
- Bootstrap：不使用/国内内置/境外内置；选择后显示将使用的内置服务器列表（只读）。
- 拉黑：隐藏线路/上游；保存后回读 `outcome.kind=reject`。

## 5. Apply 事务与长操作

### 5.1 保存 vs 应用

- 保存 = 写 desired state，返回 `desired_not_applied`；**不等于生效**。
- 应用 = `POST /runtime/apply`；真实改动 VPP/服务。
- UI 必须同时提供“保存并应用”（默认）与“仅保存”（如产品批准）；仅保存后出现全局
  “待应用 N”提示。

### 5.2 状态机 UI

| 状态 | 顶部 Banner | 行/按钮 | 允许操作 |
| --- | --- | --- | --- |
| `saved_pending` | “有 N 项配置待应用” [立即应用] | 行 Badge 待应用 | 继续编辑/应用 |
| `applying` | “正在应用 · 事务 xxx · 已用 12s” | 禁用写操作 | 查看进度/取消等待 |
| `committed` | 绿色“应用成功 · 事务 xxx · 用时 183s” | 行变已应用 | 正常 |
| `degraded` | 黄色“应用完成但部分组件降级” + 原因 | 受影响的组件标黄 | 查看原因/重试 |
| `failed` | 红色“应用失败” + 原因 + 回滚状态 | 保留 desired | 重试/回滚（若后端支持） |
| `unknown` | 灰色“状态未知，正在确认” | 禁用重复提交 | 自动轮询 |
| `apply_in_progress` (202) | “已有应用在执行 · 事务 xxx” | 禁止再次提交 | 查看进度 |

### 5.3 时序

1. 用户点“保存并应用” → `POST/PATCH` 保存。
2. 保存成功 → 立即显示“待应用”，然后 `POST /runtime/apply`。
3. `200`：直接展示结果（可能 183s 才返回）；`202`：进入轮询。
4. 轮询 `GET /runtime/status`（2–5s，页面可见时）；读取 `last_apply.transaction_id/status/
   runtime_state/components`。
5. 完成：刷新相关资源、关闭 Banner（成功）或保留（降级/失败）。
6. 超时/网络断开：不清除事务，显示“仍在确认”，继续轮询；禁止重复提交。

### 5.4 文案与证据

- 显示事务号、开始时间、已用时长、`status/runtime_state`、降级原因。
- 不显示百分比（API 无进度）。
- “查看详情”打开运行态页/抽屉，展示 components 和 last_apply。
- 失败时显示 `rollback`/`rollback_receipt` 是否存在；没有就不说“已回滚”。

## 6. 会话记录 / 筛选 / 详情（Panabit 学习重点）

### 6.1 入口

- 在线用户行 → 会话抽屉。
- 首页 Top 用户行 → 同一抽屉。
- Top 连接页 → 连接排行；点击某行可打开该 IP 的会话抽屉（若 IP 可映射）。
- 不新增独立“会话”一级页面（当前数据/分页能力有限）；如后续后端支持服务端分页/过滤，
  再升级为独立页。

### 6.2 抽屉结构

1. 头部：IP + 设备名 + 状态 + 刷新/关闭。
2. 概览：MAC、在线时长、当前速率、累计流量、租约/邻居状态。
3. 查询栏：关键字、协议、状态、清空；查询按钮（或即时过滤）。
4. 会话表：源、目的/NAT、协议、状态/时长、上行、下行；可选“推断策略/出口”。
5. 分页：20/页；显示总数；上一页/下一页。
6. 底部：关闭；可选“复制 IP”。

### 6.3 筛选规则

- 关键字匹配：源地址/端口、目的地址/端口、NAT 地址/端口（不匹配策略/出口，除非显示）。
- 协议：从当前会话集合动态生成选项 + 全部。
- 状态：若后端字段存在则动态生成；不存在不显示。
- 过滤在前端对已加载会话执行；显示“筛选后 N / 总 N”。
- 刷新时保留筛选与页码；若当前页超出范围，回到最后一页。

### 6.4 详情字段

只显示后端 `GatewayConnection`/telemetry 返回的字段：

- `src_ip/src_port`、`dst_ip/dst_port`、`translated_ip/translated_port`、`protocol`、
  `connection_count`、`bytes`、`age_seconds`、`session_kind`、`observed_at`。
- 不显示重传、最大包长、虚拟身份、共享用户、移动终端（无数据）。

### 6.5 隐私与安全

- 不在 URL/日志中暴露完整会话；抽屉关闭即清空筛选。
- 复制/导出仅当前页；导出需产品确认（当前无导出 API）。
- 只读角色可查看，不可删除会话（当前无删除会话 API）。

## 7. 错误 / 空态 / 权限

| HTTP/场景 | UI |
| --- | --- |
| 401 | 清会话，跳登录，保留 returnTo；不显示空表 |
| 403 | 区块/页面“无权限”；只读角色说明；不跳登录 |
| 404 | 资源不存在：列表刷新 + toast；详情页 NotFound |
| 409/422 | 表单顶部错误 + 字段；保留输入；显示后端 message |
| 429 | “请求过于频繁，请稍后重试”；禁用提交 5s |
| 500 | 错误块 + request_id + 重试；不吞掉 |
| 502/503/504 | “控制服务暂不可用”；保留旧数据；重试 |
| 网络断开 | 顶部离线条；“网络已断开，恢复后自动刷新” |
| 慢请求 | 骨架/“读取较慢”；>20s 可重试；不误报故障 |
| 部分能力不可用 | 模块级“不可用 + reason”；不显示 0 假数据 |

## 8. 危险操作

- 配置初始化：输入 `RESET` 或勾选确认 + 二次弹窗；说明会清空配置/重启服务。
- 固件升级：显示包名/大小/校验状态；升级中禁止其他写操作；提示可能重启/断网。
- 删除 WAN/LAN/接口：列出依赖（策略/映射/DNS/群组/代理）；后端拒绝时展示原因。
- 修改管理口：提示“可能导致当前连接中断”；保存后显示新地址与重连提示。
- 角色变更：管理口不能改为 WAN/LAN；变更可能清理依赖，必须确认。

## 9. 键盘与可访问性

| 操作 | 快捷键 |
| --- | --- |
| 全局搜索/命令面板 | Ctrl/Cmd + K |
| 关闭弹窗/抽屉 | Esc（脏表单先确认） |
| 提交表单 | Ctrl/Cmd + Enter（可选） |
| 表格上下移动 | ↑/↓（行焦点） |
| 打开详情 | Enter |
| 多选 | Space |
| 跳到主内容 | Tab 第一项“跳到主内容” |

- 焦点可见：2px accent outline；不用 `outline: none`。
- 弹窗/抽屉焦点陷阱；关闭后回触发按钮。
- 表单 label 与 input 关联；错误 `aria-describedby`；必填 `aria-required`。
- 状态 Badge 有文本；图表有 `aria-label` 和数据表替代。
- 对比度：正文 ≥ 4.5:1；大数字 ≥ 3:1；disabled 也要可辨认。
- 尊重 `prefers-reduced-motion`。

## 10. 交互差异表（现状 → 参考 → 目标）

| 场景 | 现状（Ly Route） | 参考 | 目标 | 理由/约束 |
| --- | --- | --- | --- | --- |
| 信息架构 | 系统概况/流量概况两页；网络设置过载 | iKuai 4.0 分组导航 | 概览 / 监控 / 网络 / 策略与对象 / 系统 | 首页回答“现在怎么样”，配置按任务分组 |
| 顶栏 | 只有退出 | iKuai 全局搜索 + 状态；UniFi 简洁顶栏 | 面包屑 + 搜索 + 健康/待应用 + 用户 | 快速定位与状态可见 |
| 首页 | 资源卡 + 大图，缺接口/健康/待办 | iKuai 概览：设备、WAN、KPI、图表、快捷入口 | 状态带 + 5 KPI + 趋势 + 出口/接口/健康/Top/事件 | 专业路由器首页应可排障 |
| 表格密度 | 固定高行、空表也分页 | iKuai/UniFi 高密度表 | 44px 默认、38/52 可调；空表空态 | 提升信息密度与可读性 |
| 列管理 | 无 | iKuai 列设置/自动刷新 | 列设置 + 密度 + 排序 + 客户端过滤 | 不同角色关注不同列 |
| 批量操作 | 部分页有按钮但无批量 API | Panabit 批量启用/禁用/删除 | 只在后端支持时显示；否则不做 | 不伪造成功 |
| 新增/编辑 | 单栏弹窗，复杂表单拥挤 | Panabit 分节弹窗；UniFi 抽屉 | 分节弹窗/抽屉；大表单 960px | 降低误配 |
| 保存/生效 | 保存后自动 apply，但状态提示弱 | Panabit 配置后需提交/生效 | 明确“待应用/应用中/已应用”；全局 pill | 不让用户误以为已生效 |
| 长 apply | 无进度，只等 | Panabit 操作有状态 | 不确定进度 + 事务号 + 已用时长 | API 无百分比，禁止假进度 |
| 策略路由 | 表格无命中；无默认策略引导 | Panabit 序号 1–65535、Any→Any 默认 NAT、命中计数 | 保留序号/条件/动作；空表引导默认策略；不显示命中 | 后端无 hit_count，不能抄 |
| 端口映射 | 基础字段 | Panabit 外部 IP/端口范围/回流 | 保留现有字段；高级字段待产品批准 | 不扩功能 |
| 在线用户 | 表格 + 会话抽屉 | Panabit IP 档案多 Tab | 概览 + 会话；不做虚拟身份等无数据 Tab | 数据边界 |
| 会话筛选 | 关键字/协议/策略/出口（策略/出口为推断） | Panabit 条件筛选 | 关键字/协议/状态；推断列默认移除 | 真实性优先 |
| 空态 | 空表占位行 + 分页 | iKuai/UniFi 空态引导 | 图标 + 说明 + 主操作；无分页 | 减少“坏掉”的错觉 |
| 错误 | 文本 toast | 专业控制台错误块 | 错误块 + code + request_id + 重试 | 可诊断 |
| 移动端 | 汉堡菜单；表格压缩 | iKuai 移动适配一般；UniFi 较好 | 抽屉导航、单列、关键列、全屏弹窗 | 管理页面手机应急可用 |
| 深色 | 无 | UniFi 深色 | v1 不做；tokens 预留 | 控制验收面 |

### 10.1 明确不抄的部分

| 参考能力 | 不抄原因 |
| --- | --- |
| Panabit 应用协议/DPI 匹配、Top 应用 | Ly Route 无 DPI/OAF，产品边界明确排除 |
| Panabit 用户类型/用户组/VLAN/TTL/DSCP 匹配 | 后端策略字段不支持 |
| Panabit 虚拟身份/共享用户/移动终端/账号信息 | 无数据源 |
| Panabit 全锥 NAT 的复杂规则 | 只保留后端支持的 `full_cone` 布尔；不扩展 |
| iKuai 应用市场/Docker/无线 AC | 非本产品范围 |
| UniFi 多站点/云管理/拓扑自动发现 | 单网关、无云管理；拓扑只能基于真实接口/出口 |
| 任何厂商的 logo/图标/截图/配色素材 | 商标与版权边界 |
